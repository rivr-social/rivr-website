## Image custody

- All imagery used by the primary reference pages is stored under `img/`.
- `img/home`, `features`, `membership`, `about`, `team`, `vision`, `blog`, and
  `get-started` retain full-resolution source images instead of Squarespace
  resize derivatives.
- `img/brand/rivr-symbol-{light,dark}.png` are derived from the canonical
  Global app top-left mark and supply the shared header symbol; the same mark
  is used for `favicon.png`.
- No page, stylesheet, or script loads an image from Squarespace.

The older root-level `img/sq-*` files are retained as the first-generation
local reference harvest; the named page directories are the canonical assets
for the current implementation.

## Visual-system source

The styling is derived from `repos/global/src/app/globals.css`, including Inter
typography, the light crystalline gradient (`#f9d294`, `#f0cc8b`, `#c69a62`,
`#794e1b`), the dark teal gradient, glass tints, focus treatment, and responsive
layout behavior. The website does not import application code at runtime.
